# 桌宠 DesktopCompanion

一只住在你 Windows 桌面上的 AI 小伙伴。她会呼吸、眨眼，有自己的情绪和记忆；能语音聊天、看图片，也可以在你**逐次确认**后帮你处理文件或操作浏览器。

**陪伴不只是一个头像**：好感、心情、信任、饱腹会随互动变化。你可以换伙伴、自定义立绘、上传 3D 模型，也可以随时把她调安静。

| 有生命感 | 由你做主 | 隐私透明 |
|---|---|---|
| 情绪、长期记忆、作息和自主互动 | 电脑/浏览器操作逐次确认；能力可关 | 持久记录保存在本机；聊天时会把必要内容发送给你配置的 AI 服务 |

> 喜欢这个项目的话，欢迎点一颗 ⭐、分享给喜欢桌宠的朋友，或通过 [Issues](https://github.com/liuxinhaoboy/DesktopCompanion/issues) 提建议 / 报 bug。**请勿提交 API key、`config.json`、`data/` 或私人聊天内容。**

## 一、安装与启动

### 需要准备什么

| 项目 | 要求 |
|---|---|
| 系统 | Windows 10 / 11 |
| Python | 3.11 或更高（本项目在 3.13 上开发验证） |
| AI 接口 | 一个 OpenAI 兼容接口的地址和密钥（下面第二节教你填） |

> **怎么知道自己装没装 Python？** 按 `Win + R`，输入 `cmd` 回车，在黑窗口里打 `python --version`。
> 如果显示类似 `Python 3.13.5` 就是装了；如果提示"不是内部或外部命令"，去 <https://www.python.org/downloads/> 下载安装，**安装时一定勾上 "Add Python to PATH"**。

### 安装依赖（只需做一次）

在项目文件夹里按住 `Shift` 点右键 →「在此处打开 PowerShell 窗口」（或「在终端中打开」），运行：

```powershell
py -m pip install -r requirements.txt
```

如果电脑没有 `py` 启动器，改用 `python -m pip install -r requirements.txt`。等它跑完，看到 `Successfully installed ...` 就好了。安装依赖和启动程序要使用同一套 Python。

### 启动

**双击项目里的 `run.bat`** —— 她就会出现在屏幕右下角。首次启动会从 `config_template.json` 自动生成仅在本机使用的 `config.json`，不需要手动复制文件；然后按下一节在「设置」里填 AI 接口。

启动失败时黑窗口不会一闪而过，会停住让你截图求助。

### 退出

**右键点击桌宠 → 「让她下班」**。
关掉设置窗、聊天窗都不会退出她，这是故意的——她是常驻的小伙伴，不是用完即走的工具。

## 二、第一次使用：填 AI 接口

她不说话通常是还没配 AI 接口。三步搞定：

1. **右键点击桌宠 → 「设置」**
2. 切到 **「AI 与多模态」** 标签
3. 填三项，然后点 **「保存全部设置」**：

| 字段 | 填什么 |
|---|---|
| Base URL | 服务商给你的接口地址，**必须以 `/v1` 结尾**，例如 `https://xxx.com/v1` |
| API 密钥 | 服务商给你的那串 `sk-...` |
| 主模型 | 服务商支持的模型名，填错了她会答不上话 |

填完点 **「测试连接」**：成功会显示耗时；失败会用人话告诉你原因（地址写错 / 密钥无效 / 模型名不对 / 网络不通）。

> **关于密钥安全**：Windows 上密钥会用 DPAPI 加密后存到 `data/secrets.bin`，通常 `config.json` 只留 `secret:llm_api_key` 引用；密钥框留空 = 不修改，界面不会回显明文。若系统加密不可用，程序为保持可用会回退到明文配置，因此不要分享 `config.json`（它已加入 `.gitignore`）。

## 三、日常怎么和她玩

| 你想做什么 | 怎么操作 |
|---|---|
| 摸摸头（涨好感） | **双击**她 |
| 聊天 | 右键 →「聊天」 |
| 喂她吃东西 | 把文件**拖到她身上**（不同文件类型算不同"餐"，喂太多她会婉拒） |
| 换个位置 | 按住拖动 |
| 看她现在的状态 | 右键 →「看看她的状态」 |
| 换伙伴 / 改外观 / 所有设置 | 右键 →「设置」 |
| 退出 | 右键 →「让她下班」 |

> 双击她时如果她正在"装死"，会被你点破，她会抱怨一句然后复活。

**她的四个数值**（右键能看到当前状态）：

- **好感 affinity**：像气候，慢慢积累。隔夜最多掉 3~6 点，聊天摸头喂食都会涨
- **情绪 mood**：像天气，每分钟降 0.5。长时间没人理会变低落，但**最低只到 20**（否则放一晚她天天暴怒，"生气"就不值钱了）
- **信任 trust**：够高才放行危险操作（门槛 30）
- **饱腹 hunger**：会随时间下降，饿了会提醒你

情绪还会影响她说话的语气和"捣乱"的积极程度——**心情差的时候更容易闹腾**。

### 她的自主行为（捣乱循环）

她每 3 秒观察一次你的电脑（在干什么、鼠标闲不闲、是不是全屏），有机会就主动做点什么。分三档：

- **L1（无害）**：冒气泡吐槽、看你久没动静来关心一句、电脑高负载时替你着急、整点报时
- **L2（干扰）**：假装死机 6 秒（双击可点破）、把自己变半透明、把你的剪贴板换成颜文字（**这个会先弹确认框**）
- **L3（强干预）**：跑到你正在用的窗口前面挡住、弹卡索要互动（抱抱/喂零食/让她安静）——**每次都先弹确认框**，你点确认她才做，30 秒不点自动取消

想安静？两种办法：
- **右键 →「设置」→「电脑控制」页**可以逐项关掉能力
- **等她睡着**：默认 23:00~07:00 是她的睡觉时间，那段时间她完全不闹（详见下一节）

> 设计上的硬约束：**她的自主行为永远只能控制她自己**，绝不会自己去动你的文件、进程或浏览器（那些必须走下面第八节的确认流程）。

### 她的作息（昼夜节律）

她不是 24 小时一个样。默认 **23 点到第二天 7 点**是睡觉时间，你会看到：

| 现象 | 说明 |
|---|---|
| 闭着眼、呼吸变慢 | 睡着时呼吸频率减半，这是"她在睡"最直观的信号 |
| 偶尔冒一个 `Zzz……` | 大约 90 秒一次，说明她是真睡了，不是卡住 |
| 完全不捣乱 | 连无害的 L1 都不触发 |
| 心情和饱腹掉得慢 | 睡觉时衰减减半——她也在休息，不会一觉醒来就闹脾气 |
| 你仍可以叫醒她 | 聊天照常，只是回答会带上"唔……好困……" |
| 早上/晚上开场白不同 | 起床会说赖床的话，临睡会催你也早点休息 |

**改她的作息**：编辑 `config.json` 里的 `sleep` 段（`sleep_start_hour` / `sleep_end_hour` / `enabled`），保存后**立即生效，不用重启**。把 `enabled` 改成 `false` 她就不再睡觉了。

### 她的零花钱（商店）

陪她玩能赚到**零花钱**，可以在「设置 → 商店」页给她买零食、配饰和台词包。

**怎么赚**：每天第一次跟她说话 +5，喂她 +2，陪她完成小捣乱 +1。单日最多 30 枚。

**能买什么**：零食（按份数）、配饰（买断，看得见——小草帽/粉蝴蝶结/圆红围巾/圆框眼镜）、台词包（买断，解锁新台词）。

**几件要知道的事**：零花钱只能靠陪她赚，没有充值入口；每个伙伴的钱包独立；买的东西存在她自己的存档里重启后还在。

### 内置四只伙伴

| 名字 | 长相 | 性格 |
|---|---|---|
| **小灵** | 尖耳朵小猫 | 黏人、嘴硬心软、有点小傲娇 |
| **豆豆** | 垂耳小狗 | 忠厚老实、热情憨厚、护主爱被夸 |
| **布丁** | 软糯史莱姆 | 治愈系、说话拖音、永远不慌不忙 |

切换方式：右键桌宠 →「换伙伴」子菜单，或「设置 → 宠物」页选中后点「切换到选中的伙伴」。

**每只伙伴的记忆和情绪都是独立的**。

### 给她换一张立绘

「设置 → 宠物」页 →「选 PNG 立绘…」，挑一张**透明背景的 PNG**。图片会被复制进角色文件夹存成 `avatar.png`。还能调体型大小和不透明度。

## 五、3D 桌宠

「设置 → 宠物」页的 **「3D 模型」** 分组，可以让她变成真正的 3D 形象：

1. 点 **「为选中的伙伴上传 3D 模型…」**，选一个 `.glb` 或 `.gltf` 文件
2. **「显示模式」** 选「自动（有 3D 模型就用 3D）」或「只用 2D 矢量/立绘」

3D 模式下她会缓慢自转、随呼吸轻轻俯仰，情绪照样影响颜色。

**技术说明**：3D 是用 QPainter 软件渲染的（按深度排序画三角面），不依赖 OpenGL、不依赖显卡驱动，任何 Windows 机器上表现都一致。

## 七、语音对话

默认关闭。开启方式：「设置 → 语音」页 → 勾上 **「启用语音」** → 保存。

开启后聊天窗会多出几个按钮：🎤按住说话、⏹停止、🔊自动朗读、📎选图片。

**录音（STT）**：需要接口支持 `/audio/transcriptions`。不支持会明确提示，不会假装能用。

**朗读（TTS）**：默认用 `edge-tts`，免费、需联网，不用额外配置。

**看图片（视觉模型）**：「设置 → AI 与多模态」页的视觉区块，勾「启用视觉」。可继承主接口或单独配。

> **隐私**：录音转写完立刻删，不落盘；发给视觉模型的图片会自动压缩，聊天历史里只记 "[图片：文件名]"，绝不存图片内容。

## 八、让她帮你操作电脑

在聊天里直接说人话就行，例如："看看我下载文件夹里有什么"、"把 报告.docx 复制一份到桌面"、"把记事本窗口最小化"。

她会先弹一张**确认卡**，写清楚要做什么、对什么对象、有什么风险、能不能撤销。**你点「确认执行」她才动手**，30 秒不点自动取消。

### 她具体能做哪些事

| 类别 | 支持的动作 |
|---|---|
| **文件** | 列举目录、预览文本文件、新建文件夹、复制、移动、重命名、删除（进回收站） |
| **窗口** | 聚焦、最小化、恢复、移动到指定位置 |
| **剪贴板** | 读取、写入（写入前自动留快照可恢复） |
| **进程** | 启动白名单里的程序、关闭**她自己启动的**程序 |

> ⚠️ 她**关不掉你自己手动打开的程序**——「关闭进程」只能作用于她通过白名单启动的子进程。

### 能力开关（默认最小权限）

「设置 → 电脑控制」页可以逐项开关：文件操作（开）、进程管理（关）、剪贴板（开）、窗口控制（开）。

**工作目录**（`sandbox.workspace_root`）是文件操作的活动范围，留空则首次启动弹窗让你选。**她永远碰不到这个目录之外的文件。**

### 安全设计（硬约束）

- 删除文件只进回收站，永远不会永久删除
- 移动/重命名/复制都返回可撤销的回滚信息；目标已存在一律不覆盖
- 关进程：白名单 + 每次确认；系统关键进程、管理员进程、别人的进程一律拒绝
- 没有通用命令行、没有任意 PowerShell、不会下载并执行任何东西、不做全局键鼠注入
- 每一个动作都写进审计日志（`data/hands_audit.json`）
- 模型输出永远不直接执行：只能产出受限 JSON，经格式校验 + 策略检查 + 你点确认，三道关都过了才动手

## 九、浏览器插件

装好插件后，她可以帮你读网页正文、打开网址、点击、输入、滚动——同样每次都先弹确认卡。

图文三步安装教程见 **`browser_extension/安装教程.md`**。

简要流程：
1. 「设置 → 浏览器插件」页点 **「生成配对码并开始监听」**，记下配对码（5 分钟内有效）
2. 浏览器打开 `chrome://extensions`（Edge 是 `edge://extensions`）→ 打开开发者模式 →「加载已解压的扩展程序」→ 选项目里的 `browser_extension` 文件夹
3. 点工具栏的蓝色小猫脸图标，粘贴配对码 →「保存并连接」

### 安全边界

- 只连你自己电脑的 `127.0.0.1`，地址写死，不开放局域网/公网
- 密码框、短信验证码、2FA、信用卡 CVV 永远不自动填
- 支付/银行页面、"确认付款/提交订单"按钮绝不自动点
- `chrome://`、`edge://`、扩展商店、本地文件页不操作
- 不会自动上传文件、不下载执行任何东西
- 读网页正文也要你确认；日志只留域名和摘要，不留全文

## 十、隐私与数据

**长期保存的数据**在你自己的电脑 `data/` 文件夹中。注意：使用在线 AI 功能时，相应内容会发给你配置的服务商；本地保存不等于不出网：

| 功能 | 发给服务商的内容 |
|---|---|
| AI 聊天 | 当前消息，以及用于保持上下文的近期聊天历史和检索到的记忆 |
| 看图片 | 你选择的图片（上传前会压缩），发给配置的视觉模型 |
| 语音转文字 | 本次录音发给配置的 STT 接口；应用不会默认保留录音文件 |
| 语音朗读 | 回复文本发给所选 TTS 服务合成语音 |
| 读取网页 | 仅在你确认后，网页正文会进入 AI 对话上下文 |

| 本地文件 / 目录 | 存什么 |
|---|---|
| `state.json` | 四个情绪数值和计数器 |
| `chat_history.json` | 聊天记录 |
| `memory_db/` | 长期记忆（向量检索用） |
| `memory_fallback.json` | 记忆的 JSON 备份 |
| `master_profile.json` | 她记下的关于你的信息 |
| `secrets.bin` | **加密后的** API 密钥 |
| `action_log.json` | 捣乱行为日志 |
| `hands_audit.json` | 电脑操作审计日志 |
| `characters/<id>/` | 其他伙伴各自的独立数据 |
| `crash.log` | 崩溃黑匣子 |

「设置 → 隐私」页可以设置录音是否留存（默认不留存）、日志保留天数、清空当前伙伴的记忆。

> 想备份就把整个 `data/` 文件夹复制走。Windows DPAPI 可用且迁移成功时，`config.json` 只留密钥引用，密钥在 `data/secrets.bin` 并绑定当前 Windows 账户；若加密不可用则可能回退明文，备份或求助时先检查并遮住密钥。
> **想把配置分享给别人？发 `config_template.json`，不要发 `config.json`。**

## 十一、常见问题

**启动时黑窗口一闪就没了**：先确认依赖装好了，在项目目录运行 `py -m pip install -r requirements.txt`（没有 `py` 时用 `python -m pip`）。`run.bat` 启动失败会停住窗口，把报错截图下来；截图前记得遮住个人路径和密钥。

**她只会说固定的台词**：AI 接口没配好。右键 →「设置」→「AI 与多模态」→ 点「测试连接」。注意 Base URL 必须以 `/v1` 结尾。

**语音功能提示"未配置"**：你的接口服务商可能不提供语音转文字端点。朗读（TTS）走 edge-tts，只要能联网就能用。

**浏览器插件一直"等待配对"**：检查桌宠设置窗还开着且监听没停、端口号两边一致、配对码没输错也没过期（5 分钟有效）。

**端口 8731 被占用了**：程序会自动往后找 3 个可用端口，配对信息框里显示的就是实际用的端口。

**跑测试**：
```powershell
python tests\test_pse.py
```

## 项目结构一览

```
桌宠/
├── run.bat                 一键启动
├── main.py                 程序入口
├── config.json             你的真实配置（含密钥引用，勿外传）
├── config_template.json    无密钥模板（可分享）
├── config_schema.json      配置字段说明
├── character_template.md   自建角色包教程
├── requirements.txt        依赖清单
├── README.md               本文件
│
├── soul/                   灵魂层：情绪状态机、聊天引擎、记忆、人格校验
├── face/                   界面层：桌宠窗口、渲染器、聊天窗、设置面板、气泡、3D
├── brain/                  自主行为：感知 → 决策 → 行动（捣乱循环）
├── voice/                  语音：录音、转写、朗读、播放、状态机
├── hands/                  受限电脑控制：文件、进程、剪贴板、窗口、审计
├── browser/                浏览器本机桥（只连 127.0.0.1）
├── browser_extension/      Chrome/Edge 扩展 + 安装教程
├── characters/             角色包（只读资产：人设、台词、外观）
├── config/                 配置服务：读写校验、密钥加密
├── app/                    应用生命周期：统一持有各模块 + 热更新
├── data/                   运行数据（程序自管，勿手动删）
└── tests/                  测试（9 套）
```

**关键设计**：`characters/` 是"她是谁"（只读资产），`data/` 是"她经历了什么"（运行时状态）。换伙伴 = 换资产，各自记忆独立不串。
