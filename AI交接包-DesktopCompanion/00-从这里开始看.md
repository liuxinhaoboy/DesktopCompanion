# 00 - 从这里开始看（交接总说明）

> **写给：接手开发的 AI**
> **项目：DesktopCompanion 桌面 AI 伴侣**

## 一、这个项目是什么

一个 Python + PyQt6 的 Windows 桌面宠物，核心特点：

1. **有持久情感的 AI 伴侣**：好感度/情绪/信任/饥饿四套数值，关机不丢，情绪影响说话风格和捣乱概率
2. **有长期记忆**：ChromaDB 向量记忆（自动降级 JSON），回忆带情绪标签
3. **会自主行动**：每 3 秒感知一次电脑状态，按情绪概率触发 L1/L2/L3 三级捣乱
4. **能吃文件**：把文件拖到她身上就算喂饭，不同后缀=不同餐型

## 二、最重要的约束（必须遵守）

**用户是电脑小白**。所有代码必须：
- 不引入需要编译的包
- 注释用中文，讲"为什么这样设计"
- 每个阶段交付后必须能双击 run.bat 直接跑
- 测试用纯 assert + 极简运行器风格，不依赖 pytest
- 交流全用中文
- 危险操作必须先弹确认框 + 写日志
