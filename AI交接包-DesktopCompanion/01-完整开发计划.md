## 三、设置控制中心

## 四、语音与多模态聊天

新增 voice/ 包：recorder.py / stt.py / tts.py / player.py / service.py
- ChatPanel 加按住说话按钮、停止按钮、播报开关、图片附件按钮
- 状态机：idle → recording → transcribing → generating → speaking
- 录音默认只在内存/临时文件，转写完即删
- 视觉聊天：图片压缩后发给独立视觉模型；历史只存"[已发送图片：文件名]"

## 五、中央"电脑控制"执行器

新增 hands/ 包：schema.py / policy.py / confirmation.py / executor.py / files.py / processes.py / clipboard.py / windows.py / audit.py

固定流程：聊天意图 → ToolPlanner → Policy 校验 → 确认卡片 → 用户确认 → Executor 执行前再验证 → 脱敏审计 → 结果回写

能力边界：
- 文件：只在 workspace_root 内操作；删除只进回收站；移动/删除前生成回滚快照
- 进程：启动白名单程序；关闭需每次确认；系统/管理员/受保护进程一律拒绝
- 剪贴板：预览后读写，覆盖前留快照可恢复
- 窗口：仅普通用户级窗口的聚焦/最小化/恢复/移动
- 绝不提供：通用 shell、任意 PowerShell、下载执行、全局键鼠注入、绕过确认

## 六、Chrome / Edge 插件与本机桥

browser/：bridge.py（只监听 127.0.0.1）/ protocol.py / policy.py
browser_extension/：manifest.json / background.js / content.js / options.html/js / icons/

- 设置页生成一次性配对码；插件选项页粘贴配对码
- 每条消息都要会话 token；不开 LAN/公网端口
- 浏览器动作同样逐次确认
- 默认禁止：chrome://、edge://、扩展商店、文件页、密码字段、支付/银行页、验证码/2FA、最终提交表单
