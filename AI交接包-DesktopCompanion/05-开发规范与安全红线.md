# 05 - 开发规范与安全红线

## 用户约束

用户是电脑小白：注释用中文；每阶段交付必须能双击 run.bat 跑起来；报错要翻译成人话；不引入需要编译的包。

## 代码风格

- Python 3.11+ 语法
- Qt 控件操作全在主线程；耗时操作 asyncio.to_thread
- 文件写入一律临时文件 + os.replace 原子替换
- 读取用户 JSON 一律 try/except 兜底 + 缺字段用默认值

## 测试规范

- 纯 assert + 极简运行器
- 测试只用 tempfile.mkdtemp()，绝不碰真实 data/
- 有副作用的操作必须替换成替身

## 安全红线

### 密钥
- 任何输出不回显完整 API key（最多末 4 位）

### 危险操作
- 删文件：只进回收站，永不永久删除；删除/移动前生成回滚快照
- 关进程：白名单 + 每次确认；系统/管理员/受保护进程一律拒绝
- 改剪贴板：覆盖前留快照可恢复
- L2/L3 动作：确认框 + action_log 留痕；确认 30 秒自动失效

### 权限边界
- 文件操作锁死在 workspace_root 内
- 浏览器桥只听 127.0.0.1
- ACL 永远只能控制桌宠自身，不能调 hands/ 或浏览器
- 不提供：通用 shell、任意 PowerShell、下载自动执行、全局键鼠注入

### 模型输出
- 模型只能产出受限 JSON 动作请求，经校验+确认后才执行
- 模型生成的任何代码/命令永远不直接运行
