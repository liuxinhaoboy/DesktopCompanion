# 04 - 项目结构导览

## 关键调用链

**聊天**：ChatPanel.send → engine.stream_chat → llm.chat_stream → 流式回显 → 写历史+存记忆+人格校验

**捣乱**：AgentLoop._tick_once → perceive.snapshot → decider.tick → actor.perform → action_log

**喂食**：PetWindow.dropEvent → _guess_recipe → cesm.feed → 气泡+历史

## 模块概览

| 目录 | 作用 |
|---|---|
| soul/ | 灵魂层：情绪状态机、聊天引擎、记忆、人格校验、角色管理 |
| face/ | 界面层：桌宠窗口、渲染器、聊天窗、设置面板、气泡、3D、商店页 |
| brain/ | 自主行为：感知→决策→行动、昼夜节律 |
| voice/ | 语音：录音、转写、朗读、播放、状态机 |
| hands/ | 受限电脑控制：文件、进程、剪贴板、窗口、审计 |
| browser/ | 浏览器本机桥 |
| browser_extension/ | Chrome/Edge 扩展 |
| characters/ | 角色包 |
| config/ | 配置服务、密钥加密 |
| app/ | 应用生命周期 |
| shop/ | 商城经济 |
| data/ | 运行数据 |
| tests/ | 测试（11 套） |
