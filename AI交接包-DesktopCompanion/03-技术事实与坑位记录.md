## PyQt6 坑位

1. QFontMetrics.boundingRect 只收整数 QRect
2. QWidget.screen() 返回方法对象 → 用 QApplication.primaryScreen()
3. Windows 深色模式：浅色背景必须 stylesheet 写死 color
4. QMessageBox.exec() 冻住 qasync → 用 show() + finished 信号 + asyncio.Future
5. 窗口 flags：FramelessWindowHint | WindowStaysOnTopHint | Tool | WindowDoesNotAcceptFocus
6. 相对导入模块单独跑必须 python -m soul.engine

## Windows / bat 坑位

- .bat 文件里不能有中文（cmd 按 GBK 解析）
- os.replace() 在 Windows 上是原子替换
- 鼠标闲置：ctypes.windll.user32.GetLastInputInfo

## 架构关键设计

1. CESM 是唯一情绪入口：soul/state.py
2. 情绪衰减有下限 20（time_decay_floor）
3. 好感是气候（隔夜掉 3~6 点），情绪是天气（每分钟 -0.5）
4. 记忆检索强制情绪标签过滤
5. 哈希向量不下载模型：LocalHashEmbedding 128 维 blake2b
6. 退出落盘：aboutToQuit → engine.flush()
7. 确认框全非阻塞：show+Future 模式
8. ACL 只控制桌宠自身
