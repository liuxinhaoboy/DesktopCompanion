# 浏览器插件安装教程（Chrome / Edge 通用）

这个插件让桌宠小灵在**你逐次确认后**，帮你读网页正文、打开网址、点击、输入或滚动。
它只连你自己电脑上的桌宠（127.0.0.1），不连任何外部服务器。

---

## 第一步：在桌宠里生成配对码

1. 右键桌面上的小灵 →「设置」→ 切到「**浏览器插件**」标签。
2. 点「**生成配对码并开始监听**」。
3. 「配对信息」框里会出现类似这样的内容，先不要关设置窗：

   ```
   ws://127.0.0.1:8731    配对码：ABCD-1234（5 分钟内有效）
   ```

   把**配对码**（ABCD-1234 那串）记下来，配对码 5 分钟内有效，过期再点一次重新生成即可。

---

## 第二步：以"开发者模式"加载插件

### 如果你用 Chrome
1. 地址栏输入 `chrome://extensions` 回车。
2. 打开右上角的「**开发者模式**」开关。
3. 点「**加载已解压的扩展程序**」。
4. 选择本项目里的 **`browser_extension`** 文件夹（就是装着 manifest.json 的那个文件夹）。

### 如果你用 Edge
1. 地址栏输入 `edge://extensions` 回车。
2. 打开左下角的「**开发人员模式**」开关。
3. 点「**加载解压缩的扩展**」。
4. 同样选择本项目的 **`browser_extension`** 文件夹。

加载成功后，浏览器工具栏会出现一个蓝色小猫脸图标（如果没看到，点工具栏的拼图图标📌把它固定出来）。

---

## 第三步：粘贴配对码，完成连接

1. 点一下工具栏里的**蓝色小猫脸图标**，弹出配对小窗。
2. 本机地址保持 `127.0.0.1`、端口保持 `8731`（和桌宠配对信息里一致即可）。
3. 把第一步的配对码粘到「配对码」框，点「**保存并连接**」。
4. 稍等 1～2 秒：
   - 小窗状态变成「**● 已和桌宠连上**」；
   - 桌宠设置页状态变成「**● 已和浏览器扩展连接**」；
   - 扩展图标上的角标从灰色「断」变成绿色「连」。

到这里就配好了。以后只要桌宠开着，扩展会自动重连，不用每次重新配对。

---

## 怎么用

直接在聊天里跟小灵说，例如：
- "帮我看看这个网页讲了什么" → 她会先弹确认卡，你点「确认执行」她才读正文；
- "往下滑一点" / "帮我点一下'下一页'" / "在搜索框里输入天气"。

**每一个浏览器动作都会先弹确认卡**，30 秒不操作会自动取消，你不点确认她绝不会动手。

## 她被严格限制了什么（安全设计）

- 只连本机 `127.0.0.1`，地址填别的会被拒绝；
- **密码框、短信验证码、二次验证（2FA）永远不自动填**；
- **支付/银行页面、"确认付款/提交订单"这类最终按钮绝不自动点**，需要你自己手动操作；
- `chrome://`、`edge://`、扩展商店、本地文件页不操作；
- 不会自动上传文件、不会下载后运行任何东西；
- 你可以在「设置 → 浏览器插件」里随时关掉某一类能力，或点「断开并关闭监听」彻底断开。

## 常见问题

- **状态一直"等待配对"？** 检查端口是否一致、配对码有没有输错或过期；确认桌宠设置窗还开着、监听没停。
- **刷新网页后第一次操作提示"页面没有回应"？** content 脚本在页面加载时注入，刷新后等 1 秒再让她操作即可。
- **扩展图标角标显示"断"？** 桌宠没开，或被防火墙拦了本机回环；确认桌宠正在运行，本插件不需要联网。
- **想换一台浏览器 / 重新配对？** 在桌宠设置里点「断开并关闭监听」，再重新生成配对码，到新浏览器里走一遍第二、三步。
